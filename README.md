Developed an interactive Power BI dashboard to visualize business KPIs including total revenue, gender-wise revenue split, and age-group contributions.

Used DAX (Data Analysis Expressions) to create custom measures such as total revenue, high/medium/low spender classifications, and gender-based contribution metrics.

Identified top-performing product categories and most purchased products, enabling data-driven inventory and marketing decisions.

Incorporated seasonal filtering to dynamically update all dashboard metrics and visuals based on selected timeframes.

Implemented customer-level drilldowns with a dropdown selector to display individual customer purchase details.

Hosted images using Flask on a local server, allowing dynamic image rendering within Power BI tables for enhanced visual representation.

Enabled targeted product recommendations by analyzing purchasing trends segmented by age and gender.
